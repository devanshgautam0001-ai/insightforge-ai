# 📌 Overview

InsightForge AI is an enterprise-grade predictive analytics platform built for organizations that need an intelligent decision-support system capable of transforming raw datasets into actionable business intelligence.

The platform combines modern web technologies with Machine Learning, Explainable AI (XAI), Forecasting, Live Monitoring, Enterprise RBAC, Firebase Authentication and AI-powered recommendations into a single unified dashboard.

Designed with a premium cyber-inspired interface, the application provides a complete analytics workflow from data ingestion to executive reporting.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/yourusername/InsightForge-AI.git
```

Move to project

```bash
cd InsightForge-AI
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Backend

```bash
npm run server
```
